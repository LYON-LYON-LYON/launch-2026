> 适用文件：`data.js`（数据层）

## 1. EVENTS — 全年发射事件表（当前 124 条）

每条事件占一行，字段以逗号分隔，顺序建议保持：`id → name → s → e → t → rk → rkKey → pl → satCount → site → op → opKey → cat → ty → st →（tbd/month）→ hl → src → note`。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | ✅ | 事件唯一标识。约定：中国任务 `m{月}-{序}`（如 m1-1）、星链 `sx-m{月}-{序}`、Starship `ss-m{月}`、Kuiper `kp-m{月}-{序}`、OneWeb `ow-m{月}-{序}`；8 月后有描述性 id（xw23/dfhy/jamx/zx4b/qf30/seo/zq3/lj1/ce7/cz12a/m9-0）。校验器强制唯一 |
| `name` | string | ✅ | 任务显示名（含批次/星数括注） |
| `s` | string | ✅ | 开始日期 `YYYY-MM-DD`；待定任务留空串 `""` |
| `e` | string | ✅ | 结束日期 `YYYY-MM-DD`（含窗口期任务为窗口末日）；待定留空串 |
| `t` | string | ✅ | 时刻或占位：具体时刻（"23:08"）/ "预计" / "择机" / "待定" / "窗口（已过）" / "—" |
| `rk` | string | ✅ | 火箭显示名（含 · 遥序号），如 "长征八号甲 · 遥七" |
| `rkKey` | string | ✅ | 火箭型号 key，必须 ∈ ROCKETS 或空串 `""`（待定任务） |
| `pl` | string | ✅ | 载荷描述 |
| `satCount` | number | ✅ | 实际成功入轨卫星数。**口径：仅计成功入轨，fail/delay/plan 一律为 0** |
| `site` | string | ✅ | 发射场（显示名，含海上发射说明） |
| `op` | string | ✅ | 运营方显示名 |
| `opKey` | string | ✅ | 运营方 key，必须 ∈ OPERATORS 或空串 `""`。⚠️ 注意 cat 是 `major` 时 opKey 不能填 "major"（OPERATORS 无此 key，Stage 1 已修复 m2-1）。**归口规则见 §3.2**：星链 `sx-*`→starlink、Kuiper `kp-*`→kuiper、Starship `ss-*`→spacex |
| `cat` | string | ✅ | 图例分类，枚举见 §5 CATS |
| `ty` | string | ✅ | 类型三轨，枚举：`国发`（国家发射）/ `商发`（中国商业发射）/ `国外`（国际任务） |
| `st` | string | ✅ | 状态四态，枚举：`done`（已完成）/ `fail`（发射失利）/ `delay`（已推迟）/ `plan`（计划中） |
| `tbd` | 1 | 可选 | `tbd:1` 表示无具体日期的待定任务。**tbd:1 时必须有 `month` 字段**（用于归入月份视图侧栏） |
| `month` | number | 可选 | 待定任务归属月份（1-12），仅 tbd:1 时出现 |
| `hl` | 0/1 | ✅ | 是否高亮（首页月卡亮点事件/大事记级） |
| `src` | string | ✅ | **数据来源 key，必须 ∈ SOURCES**。赋值规则见 §7 |
| `note` | string | ✅ | 备注（空串 `""` 占位，不省略字段） |

## 3. OPERATORS — 卫星运营方表

| 字段 | 说明 |
|---|---|
| key | 运营方唯一标识。**同样强制查重**（Stage 0 修过 oneweb 重复） |
| `name` / `short` | 全名 / 短名 |
| `type` | 星座/任务类型 |
| `plan` | 规划规模 |
| `inOrbit` | 在轨状态静态快照字符串。**v8 起仅作无基准运营方的回退文案**（可计数运营方以 inOrbitBase 派生计算为准） |
| `inOrbitBase` | **[v8·可选]** 基准在轨数（非负数，校验器 R12 强制）。该星座截至 `inOrbitBaseDate` 的官方在轨数，作为派生计算的基数 |
| `inOrbitBaseDate` | **[v8·可选]** 基准日期 `YYYY-MM-DD`，与 `inOrbitBase` **必须成对出现**（校验器 R12）。增量只统计 `s > 此日期` 的成功事件 |
| `note` | 备注 |

### 3.1 在轨数派生口径（B5）

页面展示的"在轨状态"由 `inOrbitNow(opKey)` 派生计算：

```
inOrbitNow(opKey) = inOrbitBase + Σ(opKey 匹配且 st=done 且 s > inOrbitBaseDate 事件的 satCount)
展示格式：约 N 颗（截至 DATA_ASOF）
```

- **单一事实源**：录入新成功批次即在轨数自动累加，无需改 OPERATORS 表；
- **边界**：`s === inOrbitBaseDate` 当日事件不计入增量（基数已含）；
- **回退**：无 `inOrbitBase` 的运营方（载人/探月/组网中无官方数）显示旧 `inOrbit` 文案或 "—"；
- 当前可计数运营方（7 家）：`yuanxin`(238@2026-07-05)、`cmcc`(2@2026-06-09)、`tianqi`(41@2026-05-07)、`dfhy`(2@2026-08-05)、`starlink`(7700@2026-08-25)、`kuiper`(81@2026-08-12)、`oneweb`(648@2022-12-31)。

### 3.2 星链/Kuiper opKey 归口规则（v8）

| 任务类型 | id 前缀 | opKey | 说明 |
|---|---|---|---|
| 星链组网批次 | `sx-*` | `starlink` | 统计归口星座条目（**v8 迁移**，原为 spacex） |
| Kuiper 组网批次 | `kp-*` | `kuiper` | 统计归口星座条目（**v8 迁移**，原为 amazon） |
| Starship 试飞 | `ss-*` | `spacex` | 厂家兜底条目，不计在轨 |
| —（兜底） | — | `spacex` / `amazon` | OPERATORS 中的厂家视角条目，仅作归口兜底，不写 inOrbitBase |

- 事件卡片显示名（`op` 字段，如 "SpaceX·星链"）**不受归口影响**，只改统计口径；
- `findOperatorKey` 映射已同步："星链"→starlink、"Kuiper/亚马逊"→kuiper、"SpaceX/Falcon"→spacex。

## 8. DATA_ASOF — 数据基准日期

- 当前值 `"2026-08-31"`，含义：数据整理/核实的截止日期；
- 页面 header 与 footer 的"数据截至"文案均引用此常量（JS 启动时填充 `#asofDate`/`#asofDate2`），**改数据时同步更新此常量，不要硬编码日期到 HTML**；
- 阶段 3 接入 Launch Library 自动同步后，由流水线自动更新。

## 9. 数据维护流程（改数据 → 跑校验 → 提交）

```
① 编辑 data.js（事件/厂家/大事记…）
   └─ 新增 done/fail 事件时必须带 src；tbd 事件带 month
② 跑校验：node scripts/validate-data.js
   └─ 有 FAIL → 按报告行号修数据，重新跑，直到 ALL PASS
③ 浏览器双击 index.html 抽查改动点
④ git add -A && git commit -m "描述这次改了什么"
   └─ 提交前校验不过的 data.js 禁止入库（校验器 exit 1 即拦截）
```

常见报错对照：

| 报错 | 原因 | 修法 |
|---|---|---|
| 重复 key | ROCKETS/OPERATORS 同名 key 静默覆盖 | 删旧行或改 key |
| rkKey 不存在 | 事件引用了 ROCKETS 没有的型号 | 补 ROCKETS 条目或改 rkKey |
| done/fail 缺 src | 忘记标来源 | 按 §7 决策表补 |
| tbd 缺 month | 待定任务无法归月 | 补 month:N |
| 日期格式非法 | s/e 不是 YYYY-MM-DD 或空串 | 改格式 |
| R12 base/date 不成对 | OPERATORS 只写了 inOrbitBase 或只写了 inOrbitBaseDate | 两字段同时写或同时删 |
| R12 base 非非负数 / date 非法日期 | inOrbitBase 为负数/非数值，或 inOrbitBaseDate 格式错误 | 改为非负数值 / YYYY-MM-DD 合法日期 |
| R13 [WARN] 过期计划事件 | st=plan 但窗口末日 e 已早于 DATA_ASOF（窗口已过） | 回填真实状态：改 st 为 done（补 satCount/src）/ fail / delay（参照 qf30→delay 先例） |
